# Crest Bay Heat

An original open-world crime game set in the sun-soaked coastal city of Crest Bay. Steal cars, outrun the cops, and run six story missions for fixer Mara Voss.

## How to run

```sh
npx serve game
```

or open `game/index.html` in a desktop browser. No build step, no network — every file the game loads lives under `game/`.

## How to play

- **WASD** — walk / drive · **E** — enter or steal a car · **Mouse + Click** — aim & shoot
- **Space** — handbrake · **M** — start the next mission · **P** — pause · **N** — mute

## What is in the game

- A city to explore on foot and by car: road grid, park, beach and sea, landmarks
- Traffic and pedestrians that react to gunfire and crashes
- Stealable cars, including a gold coupe in the final mission
- A wanted level (0–5 stars) with police cars and foot cops who chase, ram and bust
- Six story missions with cash rewards, plus free roam after the finale
- Combat with mouse-aimed shooting and rivals who shoot back
- HUD with cash, health, wanted stars, objective line and a live minimap
- Start menu, pause, help, wasted / busted screens, and localStorage saves
- Synthesised WebAudio sound (engine, sirens, gunfire, crashes) and particles
